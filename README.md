# 2027학년도 관내 고입 진학지도 협의회 페이지

깃허브 페이지(GitHub Pages)에 올려 쓰는 버전입니다. 연동은 세 가지입니다.

| 연동 | 하는 일 |
|---|---|
| **구글 시트** | '공개 집계' 탭의 숫자(희망자 수, 커트라인, 석차 분포)를 5분마다 자동으로 가져와요. |
| **파이어베이스** | 메모·공지·협의 결정을 자동 저장하고, 같은 페이지를 연 모든 화면에 실시간으로 반영해요. |
| **깃허브** | 페이지를 인터넷 주소로 올려요. 링크만 있으면 계정 없이 열 수 있어요. |

설정 전에도 페이지는 작동해요. 이때 숫자는 페이지에 적힌 값이 그대로 나오고, 메모는 그 브라우저에만 저장돼요.

---

## 1. 구글 시트 연결 (5분)

1. 진학 희망 조사 시트를 열고 **파일 > 공유 > 웹에 게시**를 고릅니다.
2. 링크 탭에서 첫 번째 상자를 **'공개 집계'** 탭으로, 두 번째 상자를 **쉼표로 구분된 값(.csv)**으로 고릅니다.
   - ⚠️ 반드시 '공개 집계' 탭만 고르세요. '전체 문서'나 학생 명단이 있는 탭을 게시하면 학생 정보가 인터넷에 공개돼요.
3. **게시**를 누르고 나온 주소를 복사합니다.
4. `index.html`에서 `sheetCsvUrl: ''` 따옴표 안에 붙여 넣습니다.

'공개 집계' 탭에는 학교별 숫자만 있고 학생 이름·반·번호는 없어요. 시트가 바뀌면 구글이 게시본을 몇 분 안에 갱신하고, 페이지는 5분마다(또는 새로고침 버튼으로) 다시 읽어요.

## 2. 파이어베이스 연결 (10~15분)

1. https://console.firebase.google.com 에서 **프로젝트 만들기** (이름 예: goheung-council). 애널리틱스는 꺼도 됩니다.
2. 왼쪽 메뉴 **빌드 > Firestore Database > 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`
   - 모드: **프로덕션 모드**
3. Firestore의 **규칙** 탭을 열고, 이 폴더의 `firestore.rules` 내용을 전부 붙여 넣은 뒤 **게시**합니다.
4. 프로젝트 개요 옆 톱니바퀴 > **프로젝트 설정 > 내 앱 > 웹(</>)** 으로 앱을 추가합니다. (호스팅 체크는 하지 않아도 됩니다.)
5. 나오는 `firebaseConfig = { ... }`의 중괄호 부분을 복사해 `index.html`의 `firebase: null`을 바꿉니다.

```js
firebase: {
  apiKey: "AIza...",
  authDomain: "goheung-council.firebaseapp.com",
  projectId: "goheung-council",
  appId: "1:1234567890:web:abcdef"
}
```

6. `room` 값은 협의회마다 다른 이름으로 바꿔 쓸 수 있어요. 같은 이름을 쓰는 화면끼리 메모가 공유돼요.

연결되면 화면 위쪽 표시가 **'실시간 저장'**으로 바뀌어요.

## 3. 깃허브에 올리기 (5분)

1. https://github.com 에서 **New repository** → 이름 예: `goheung-council` → **Public** → 만들기
2. **Add file > Upload files**로 `index.html`을 올리고 **Commit changes**
3. **Settings > Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 **Save**
4. 1~2분 뒤 `https://아이디.github.io/goheung-council/` 주소로 열립니다.

나중에 내용을 고칠 때는 깃허브에서 `index.html`을 열고 연필 아이콘으로 수정하면 됩니다.

## 4. 관리자만 고칠 수 있게 하기

페이지는 누구나 볼 수 있지만, 메모·공지·협의 결정·추가 안건은 **관리자 비밀번호로 로그인했을 때만** 고칠 수 있어요.

1. 파이어베이스 콘솔 **Authentication > 로그인 방법**에서 **이메일/비밀번호**를 사용 설정하고 저장합니다.
2. **Authentication > 사용자 > 사용자 추가**에서 이메일 `admin@goheung-council.com`, 비밀번호는 원하는 값(6자 이상)으로 만듭니다. 이 이메일은 로그인용 이름일 뿐이라 실제 메일함이 없어도 돼요.
3. Firestore **규칙** 탭에 새 `firestore.rules` 내용을 붙여 넣고 **게시**합니다.
4. 페이지 왼쪽 아래 **관리자 로그인**을 누르고 비밀번호를 입력합니다.

비밀번호는 페이지 코드에 들어 있지 않아요. 바꾸고 싶으면 Authentication > 사용자에서 해당 계정의 비밀번호를 재설정하면 됩니다.

## 꼭 알아 두실 점

- **메모에 학생 이름 등 개인정보를 적지 마세요.** 고치는 건 관리자만 할 수 있지만, 보는 건 주소를 아는 누구나 할 수 있어요.
- 파이어베이스 `apiKey`는 원래 공개되는 값이라 페이지에 넣어도 됩니다. 보안은 규칙 파일이 담당해요.
- 두 사람이 같은 칸을 동시에 고치면 마지막에 저장된 내용이 남아요.
- 백업: 파이어베이스 콘솔의 Firestore 데이터 화면에서 `councils` 문서를 언제든 확인할 수 있고, 페이지의 **JSON 내보내기**로 파일 백업도 할 수 있어요.
- 무료 요금제(Spark) 한도 안에서 충분히 쓸 수 있는 규모예요.
